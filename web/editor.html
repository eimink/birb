Song structure

PATTERNS row: your pattern library. Click to edit, drag to the order row to arrange.

ORDER row: the song sequence — patterns play left to right, then loop. Drag patterns here from the PATTERNS row to add them. Drag order slots to reorder. Drop a pattern onto an existing slot to replace it. Use - to remove the selected position.

The same pattern can appear multiple times in the order — edit once, it updates everywhere.

Rec (toolbar) gates all pattern editing. Off = free play: the pattern is read-only — note keys only audition the current instrument, and note/hex entry, clear, cut and paste do nothing. Navigation, selection and copy still work. On = record: notes write at the cursor when stopped, or onto the playing row (cursor follows the playhead) while playing. In the instrument editor, note keys always audition the instrument being tweaked.

Synth types

Pick from the Wave dropdown on each instrument. Each type reveals its own parameter panel.

PulseClassic square, variable duty (12.5/25/50/75%)
TriangleSmooth, good for bass and kicks
SawtoothBright, aggressive
NoiseLFSR noise — snares, hats
SinePure tone
SampleADPCM WAV playback (load in SAMPLES tab)
FM2-op (carrier+modulator) or 4-op with 8 algorithms. Ratio/level/ADSR per op, feedback, mod index. Presets: Bass, Bell, Organ, Brass (2-op), Violin, BRAAAAM (4-op)
KSKarplus-Strong pluck. One damping knob — low = ringy, high = muted click
DrumAlgorithmic kit: Kick/Snare/Hat/Clap/Tom/Crash. Tune/Decay/Tone/Snap re-purpose per algo. 9-preset library (808, 909, Rim, Closed/Open Hat, etc.)
FormantSource wave → 3 vowel bandpass biquads. Pick Vowel A and B (A/E/I/O/U); Sweep bounces A↔B

Gate unused types at build time with -DBIRB_NO_FM, -DBIRB_NO_KS, -DBIRB_NO_DRUM, -DBIRB_NO_FORMANT, -DBIRB_NO_SAMPLES. Each strips its engine code + shaves Brotli bytes for intro builds.

Channels

Channel count is set per song (4..16, even). When > 4, a bank pager appears above the grid — arrows page through groups of 4. Cursor auto-follows into its bank when you tab between channels.

Exports

Save .bsb — binary song file. Load it back into the tracker or convert with birbc.

Export .js — self-contained JS file with synth engine + song data. Include it in your demo and call: 

var ctx = new AudioContext({sampleRate:44100});
var m = birb(ctx);
var b = ctx.createBuffer(1, m.T, 44100);
b.getChannelData(0).set(m.o);
var s = ctx.createBufferSource();
s.buffer = b;
s.connect(ctx.destination);
s.loop = true;
s.start();

Sync visuals: m.spt = samples per tick. Derive beat position from ctx.currentTime.

Export .min.js — same but minified and packed for size-coded demos. Shows estimated Brotli size after export.
